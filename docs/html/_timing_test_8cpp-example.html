Fast driver for LCDs on I2C for Pi-Pico and Arduino
TimingTest.cpp

This is a C++ example which tests the timing of the Fast-LCD-I2C driver. The driver is compared against a user supplied "brand X" driver which has sources names xLCD_I2C.cpp and xLCD_I2c.hpp. The benchmark is to update four fields of six characters each. Each field requires a setCursor command before the field is written.
